# 🤖 Rule-Based Chatbot

## CodeOrbit Tech – Artificial Intelligence Internship

### Task 1: Rule-Based Chatbot

## 📌 Project Description

This project is a simple Rule-Based Chatbot developed using Python. It responds to user inputs using predefined rules and keywords.

The chatbot can handle common greetings, simple questions, thank-you messages, and unknown inputs using a fallback response.

## 🎯 Objectives

* Build a simple chatbot using Python.
* Respond to user input using predefined rules.
* Handle common greetings and questions.
* Provide a fallback response for unknown inputs.
* Understand basic rule-based decision-making.

## 🛠️ Technologies Used

* Python
* If-else statements
* String processing

## ⚙️ Features

* Greeting responses
* Name-related questions
* Help responses
* Purpose-related questions
* "How are you?" response
* Thank-you response
* Exit commands
* Fallback response for unknown inputs

## 🧠 How It Works

1. The user enters a message.
2. The program converts the input to lowercase.
3. The chatbot checks the input against predefined keywords and rules.
4. If a matching rule is found, the corresponding response is displayed.
5. If no rule matches, a fallback response is displayed.
6. The chatbot continues until the user enters `bye`, `exit`, or `quit`.
